# Security policy

Security fixes apply to the `main` branch only. Car Rental Web is an undeployed portfolio project, uses Stripe test mode and has no bug bounty.

To report a vulnerability privately, open the repository's **Security** tab, select **Advisories**, then select **Report a vulnerability**. Keep vulnerability details out of public issues and pull requests. [GitHub private reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

Include the affected commit and component, reproduction steps, expected and observed behavior, and the potential impact. Redact credentials and personal data.
